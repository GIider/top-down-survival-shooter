Sound

Export / import

Tweaks are saved in this browser and are used by the game when you open game.html?sfxLab=1. To bring them back into the repo, copy or download the export below and replace src/audio/soundCatalog.js, then run npm run build.

Import

Paste an exported catalog module, a JSON object ({"gunShot": [1, .05, 220]}) or a single ZzFX array (applies to the selected sound).
